این خطا هم مشکل ایجاد می‌کند، مثلاً ممکن است یک تراکنش قانونی اشتباهاً مسدود شود

 Experiment 1

 Scaling had a very big impact on the performance of KNN. 
 Without Scaling, Recall was 2.1% and F1 was 4.1%, while after Scaling, 
 Recall increased to 68.4% and F1 increased to 79.8%. So in this dataset, 
 Scaling is very important for KNN.

 Experiment 3 

 By decreasing the Threshold from 0.5 to 0.3, Recall increased 
 from 57.89% to 64.21% and F1 increased from 68.75% to 72.62%, 
 while Precision decreased slightly from 84.62% to 83.56%. Increasing 
 the Threshold to 0.7 decreased Recall and F1. Therefore, in the values
 ​​examined, Threshold=0.3 showed better performance for fraud detection.
